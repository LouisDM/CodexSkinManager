# Codex Skin Manager v1.0.1 — 孟川双皮肤首发

这是 Codex Skin Manager 的首个公开版本，包含修复后的玄刃夜行、红莲业火和原生 macOS 皮肤管理器。

## 下载内容

- `Codex-Skin-Manager-v1.0.1-macOS.zip`：macOS 管理器，内置两套皮肤。
- `Meng-Chuan-Nightblade-1.0.1.codexskin`：孟川 · 玄刃夜行。
- `Meng-Chuan-Red-Lotus-1.0.1.codexskin`：孟川 · 红莲业火。
- `SHA256SUMS.txt`：全部 Release 资产的 SHA-256。

## 使用方法

1. 下载并解压管理器 ZIP，将 `Codex 皮肤管理器.app` 移到 `~/Applications`。
2. 应用使用 ad-hoc 本地签名，尚未使用 Apple Developer ID 公证。首次打开如被 macOS 阻止，请在 Finder 中右键应用并选择“打开”。
3. 确保官方 Codex 位于 `/Applications/ChatGPT.app`。
4. 打开管理器，选择内置皮肤并点击“切换到此皮肤”；也可以双击单独下载的 `.codexskin` 导入。
5. 如果 Codex 已按普通模式运行，管理器会等待你在 Codex 中按 `⌘Q`，再以仅绑定 `127.0.0.1:9340` 的本地调试会话重新启动。

## 本版重点

- 修复玄刃夜行仍使用旧启动器选择器、导致管理器误报切换成功的问题。
- 注入成功前强制校验模板运行时标记。
- 修复恢复默认后无法在同一渲染进程再次应用皮肤。
- UI 区分“上次使用”和“已验证生效”，并支持重新应用、失败重试和直接查看日志。
- 两套皮肤均可作为非商用同人皮肤包公开下载，并保留独立素材声明。

## 完整性校验

```bash
shasum -a 256 -c SHA256SUMS.txt
```
