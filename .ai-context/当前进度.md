# 当前进度

## 目标

- 维护并发布原生 macOS `Codex Skin Manager`，让 `.codexskin` 的导入、切换、恢复和故障自救可信、可测试、可跨设备继续开发。
- 当前交付目标：将仓库转为公开，发布管理器和两套可直接下载导入的非商用同人皮肤。
- 当前开发目标：在不公开受限素材的前提下，将“柳七月 · 不死凰焰”旧 `.command` 启动器安全迁移到管理器 1.1.0。

## 下一步

- 新设备克隆公开仓库后先执行 `加载上下文`。
- 开发前运行：`npm install && npm test`。
- 重建发行资产：`npm run build:release`。
- 下一版本发布前必须更新版本、Release 说明和 `SHA256SUMS.txt`，并从 GitHub 回下载复核。
- 跨设备使用柳七月皮肤时，需通过私人渠道单独传输 `.codexskin`；克隆公开仓库只能获得支持该包的管理器代码，不会获得受限素材。
